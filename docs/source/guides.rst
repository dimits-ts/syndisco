Guides
======

We provide four short tutorials on how to use SynDisco. At the end of these
tutorials, you will understand how to set up and execute a synthetic
discussion, annotate it, as well as how to generate and manage up to hundreds
of discussions. Alternatively, you can jump right into a real, use-case 
scenario and take it from there.
